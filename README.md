# Portfólio – Luan Luna

Next.js (App Router) + React. APIs: Open-Meteo (Home) e GitHub REST (Projetos).

```bash
npm install
npm run dev      # http://localhost:3000
```

Antes de publicar, edite `GITHUB_USER` em `lib/data.js`.
Deploy: suba no GitHub e importe o repositório na Vercel (sem configuração extra).
